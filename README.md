# КР3 — адаптивная версия ShopProject

Шаймарданов А. О., ЭФБО-03-25.

Основа проекта — пять страниц и основные стили КР1. Исходные товары, цены, фотографии и баннер сохранены. Для запуска откройте index.html в браузере.

| Файл или папка | Назначение |
| --- | --- |
| index.html, catalog.html, product.html, order.html, contacts.html | Страницы магазина из КР1 |
| css/style.css | Основные стили КР1 |
| css/responsive.css | Адаптация под разные экраны |
| js/main.js | Открытие диалога и подтверждение проверки формы |
| images/ | Фотографии КР1 и два WebP-варианта фото товара |
| lighthouse/ | Отчёты проверки доступности |

## Что сделано

- Базовая раскладка рассчитана на телефон. От 640 px товары идут в две колонки, от 768 px фото и описание товара стоят рядом, от 1024 px на главной три колонки, а категории каталога располагаются слева.
- Пункты меню переносятся на следующую строку средствами Flexbox. Панель категорий сворачивается через details, а её ссылки ведут к карточкам.
- Ширина изображений ограничена контейнером. Для фото товара браузер выбирает WebP через picture, srcset и sizes. JPEG служит запасным вариантом.
- Таблица остаётся таблицей на всех экранах. Если она шире контейнера, прокручивается только её обёртка.
- Поля формы имеют подписи и встроенные ограничения HTML. Диалог открывается через showModal(), закрывается по Escape и возвращает фокус к кнопке. Есть ссылка пропуска к содержимому и видимый фокус. Формы учебные, данные не отправляются.

## Что показать на защите

1. На главной установите 360 px в режиме устройств. Покажите перенос пунктов меню и одну колонку товаров.
2. Переключитесь на 768 и 1024 px. Покажите сетку, панель категорий и страницу товара.
3. На телефоне прокрутите таблицу внутри блока. Покажите picture в product.html.
4. Нажмите Tab на главной, перейдите к содержимому и откройте «Заказать». Закройте окно по Escape.
5. Попробуйте отправить пустую форму заявки, затем заполните её тестовыми данными. Покажите отчёты Lighthouse.

## Результаты проверки

Проверены все пять страниц на ширинах 360, 430, 768, 1024 и 1440 px. Общей горизонтальной прокрутки нет. Также проверены загрузка изображений, ссылка пропуска, закрытие диалога по Escape, возврат фокуса и формы.

Lighthouse Accessibility показал 100/100 на каждой странице. Отчёты находятся в lighthouse/.
